# HardMod

Utilidades de endurecimiento server-side del pack Hard Death: mobcap, mesa de
encantamientos, aldeanos, encantamientos de tridente, recompensas de cámaras de
prueba y anuncios de cambios, para Minecraft 26.2 (Fabric).

- **Minecraft**: 26.2 · **Loader**: Fabric · **Lenguaje**: Kotlin (fabric-language-kotlin)
- **Lado**: solo servidor

## Compilar

```bash
./gradlew build
```

El jar queda en `build/libs/`.

## Documentación

Ver [docs/](docs/README.md) para cómo está armado por dentro: arquitectura,
detalle de cada feature, y referencia completa de `/hardmod`.

## Distribución y actualizaciones

Este mod se distribuye vía [hd-updater](https://github.com/NicolasBeatum/hd-updater),
que compara la versión instalada contra la última release.
